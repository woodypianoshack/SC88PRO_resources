Using the insertion effect

One insertion effect is shared by the whole unit; any number of parts can be routed through it. Selecting a type sets all its parameters to suitable values. Not available for group B parts in MODE-2.

Song header

The order the manual recommends at the start of a song. Use only one reset message per song, and leave at least 50 ms after it.

StepMessageBytes
1System Mode Set (MODE-1, 32 parts) — or GS ResetF0 41 10 42 12 00 00 7F 00 01 F7
GS ResetF0 41 10 42 12 40 00 7F 00 41 F7
2Wait ≥ 50 ms
3Per channel: CC0 variation, CC32 = 3 (Native map), Program ChangeB0 00 vv B0 20 03 C0 pp
Avoid “GM System On” (F0 7E 7F 09 01 F7) for SC-88Pro songs: it switches Rx Bank Select and NRPN off, so variations and NRPN edits are ignored until a GS Reset.

Map select (CC32)

The SC-88Pro holds three sound maps. Bank Select LSB chooses which one a part uses; all the lists you have are for the Native map.

CC32Map
0Whatever the front-panel map button is set to
1SC-55 map
2SC-88 map
3Native (SC-88Pro) map
Always send CC0 and CC32 together, then Program Change: the bank change only takes effect on the Program Change. On drum parts, Program Change is ignored if CC0 is not 0.
